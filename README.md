# Basit Blackjack Oyunu

Python ile öğrenme amaçlı geliştirilmiş, terminal tabanlı basit bir Blackjack (21) oyunu.

## Özellikler
- Terminal (komut satırı) üzerinden oynanış
- Dinamik As (A) kartı değeri (el puanına göre otomatik olarak 11 veya 1 sayılır)
- Kasa mantığı (kasa 17 veya üzerine ulaşana kadar kart çeker)
- Kullanıcı girdileri için temel doğrulama ve hata kontrolü

## Gereksinimler
- Python 3.x

## Nasıl Çalıştırılır?
Oyunu başlatmak için terminalde aşağıdaki komutu çalıştırın:
```bash
python main.py
```
